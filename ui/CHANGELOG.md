# Changelog

## 0.1.0

`mix muro.ui path.muro` opens one checked book. The page draws one node for each spec, evidence, and run, one edge for each use, and a session as a compound node holding the configurations the meeting proved. A backend switch redraws the OTP, FSM, C, Rust, or Zig outline without checking the book again. A click shows the source location, and an edge also shows the out-of-order refusal.

The package depends on `muro ~> 0.20.5`. It does not emit code and it does not change the wall.
