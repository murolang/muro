# Limits

In brief: this is what the parser and checker refuse today. It is a description of the language, not a version number and not a list of things to add later.

## The checker does not accept

- `Type : Type`
- A kind as a small type: `Π (x : A) → Type : Type`, `Type × A : Type`, a constructor field of type `Type`
- Cubical primitives
- Tactics
- Implicits
- Unification
- Metavariables / unification (`?` is an unsolved goal that always fails; it does not unify)
- Quantities other than affine, `+`, and `-`
- User-defined ν-predicates (Stream, Always, and `~` are the ones that exist)
- `+` on Stream
- `+` on Either, or on `P → Empty`
- Typing raw Elixir
- Emitting spec or evidence
- Identity on `F32` or `Tensor F32 S`
- Treating `I64` as `Nat`
- A second index language for tensor shapes
- Redeclaring Nat, Unit, Empty, or Stream as `data`
- A fourth term representation
- Raw HOAS (`Tm → Tm`) as inductive syntax
- Tags other than `run`, `run internal`, `spec`, `evidence`

## Former names (history, not syntax)

The language was once described as *nothing dead runs* and *a proof never becomes a run*. Those words are not tags. The tags are `spec`, `evidence`, and `run`.

## What is proved, and what is not

- The mode wall is proved for the core fragment in `agda/Muro/Wall.agda`.
- In `agda/Muro/Consistency.agda`: no closed normal evidence term has type Empty, closed evidence terms make progress, and a reduction step keeps the type of closed evidence (preservation, from `agda/Muro/Typing.agda`). Conversion is a congruent relation generated by a confluent parallel reduction (`agda/Muro/Reduction.agda`, `agda/Muro/Convert.agda`), and the modules are checked under `--safe`.
- The fragment these are proved for is Π, λ, application, Nat, Unit, Empty, identity, `rewrite`, `def`, annotation, pairs (`A × B`, `(a, b)`, `let (a, b) = e in t`), and `data` with constructor applications and `match`, on indexed data types too (`⇒-mData`: the motive is a telescope over the indices and the scrutinee, a branch is typed at its constructor's own indices, a constructor whose numeral index clashes with the scrutinee's is skipped). ν, Tensor, and Atom are not in ⊢. ⊢ does not check `data` declarations (positivity, small fields); `Check.checkData` does. A field is strictly positive after unfolding: `D` is absent, or `D` heads a spine whose arguments do not contain `D`, or `D` occurs only to the right of a `Π` whose domain does not contain `D`. `D` inside an argument of `D` is refused. Another data type is not opaque: its fields are held to the same test, so `D` stored there and placed in a domain is refused. Run and evidence definitions that reach each other descend on one shared argument; spec does not.
- Preservation is proved for derivations in every mode (`Typing.pres`), given a signature whose bodies have their declared types (`WfSig`).
- The executable checker is sound for ⊢ on the fragment (`agda/Muro/Soundness.agda`, with `Soundness/Conv.agda` and `Soundness/Views.agda`): if `Check.infer`, `check`, or `checkTy` answers yes on a fragment term over a fragment signature whose constructor types are telescopes ending in the data type at its parameters and indices (`GoodSig`), ⊢ has a derivation with the same uses, and the type `infer` returns is convertible to the one ⊢ infers. `checkSig-sound` lifts it to whole signatures: every definition Check accepts has its type well-formed and its body derivable in ⊢. This is one direction only (no completeness), for the ⊢ fragment only. `Muro.Check` and the soundness modules are checked under `--safe`: no postulates, no `TERMINATING` pragmas. The theorem holds for every value of the fuel.
- The checker is fuelled, and running out is not a verdict. Fuel bounds reduction (`whnf`, conversion, `isData`, the index-clash test); everything else is structural recursion on the term. When the fuel runs out the answer is the error `out of fuel (the checker gave up reducing; raise the fuel)`, never a silently unreduced term and never a type error. Raise it with `mix muro.check --fuel N path.muro` (default `2000`) and check again; there is no resumption. A term that needs more fuel than any you give it is refused, not accepted: fuel caps what the checker tries to prove, not what it proves. Removing the cap waits on normalisation, the same open hypothesis as `Empty-evid`.
- Spec is not a logic. A spec definition is not checked for descent, so a spec term of an identity type carries no guarantee: `def bogus : spec Π (n : Nat) → {n ≡ suc(n) : Nat} := λ (n : Nat) → bogus n` is accepted. Such a term may be passed where an erased equation is expected and, since 0.8.0, a type may `rewrite` along it; the result is a type that never reduces, not a proof of anything. Evidence is the logic: a `rewrite` in a run or evidence term reads an evidence equation, and evidence checks descent. The fuel cap is what bounds a spec computation inside a type; removing it would need descent for spec too.
- The full consistency statement (`Empty-evid`) is not proved. Normalisation of closed evidence is its one open hypothesis (`Empty-evid-from`).
- `Type` is impredicative and kinds are not small types. Before the kind/small-type distinction was enforced, the checker accepted `Π (x : A) → Type : Type`, which retracts `Type` into a small type; that was a bug in the calculus, not in a program, and it is fixed in both Agda and Elixir.
- Example twins are not a proof that a `.muro` file is correct.

## If you need a hole

Write `?`. The checker answers with the expected type and the context, then refuses the book. Fill the hole. `?` is not a metavariable and it is not in ⊢: a derivation never contains one.

If conversion fails, the error is in surface syntax (`Fin n`, `{n ≡ 0 : Nat}`). Write a `rewrite` or a `match` until `refl` checks.

That is the language.
